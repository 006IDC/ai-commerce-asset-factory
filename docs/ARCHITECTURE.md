# Architecture

## 运行组件

ThinkPHP 8 应用负责身份、商家权限、商品资料、提示词模板、任务、定价、点数、素材、内容安全和操作记录。

Sub2API 是独立模型网关，负责上游账号、模型路由、并发控制和请求日志。业务应用保存模型配置和每次任务的实际选择结果。

ComfyUI 是可选的回环工作流运行时，只服务于画布 AI 编辑。Ark Bridge 是可选协议适配层，仅在需要适配特定上游协议时部署。

## 主链路

```text
商品资料 / 用户要求 / 素材类型 / 画幅语言 / 参考图
  → 一个完整提示词模板
  → ThinkPHP 任务队列
  → Sub2API
  → 结果校验、存储、结算和交付
```

商品主图、套图、详情页、自由创作和视频均使用这条直连链路。商品识别同样通过 Sub2API 视觉模型生成可编辑的产品报告。

画布编辑的特例链路：

```text
画布操作
  → ThinkPHP 权限、任务和结算
  → 回环 ComfyUI
  → 受控节点调用 Sub2API
  → ThinkPHP 存储与交付
```

## 提示词边界

- 管理员直接维护完整模板正文。
- 运行时将已确认商品资料、用户要求、素材类型、画幅、语言和参考图要求填入模板。
- 最终提示词直接提交给所选模型，不增加额外的中间编排层。
- 任务失败时返回明确状态，由用户决定是否重试。

## 可靠性与安全

- 提交使用幂等键，任务与点数预留/退回在业务层可追溯。
- 远程媒体下载限制为 HTTPS 公网地址，拒绝 URL 凭据、私网/保留地址、非标准端口和自动重定向。
- 上传文件执行大小、MIME 和图像解码检查。
- 内容安全可按部署策略失败关闭，不可把“审核服务不可用”当作“内容已安全”。
